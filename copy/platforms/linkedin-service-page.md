## Setup choices

- Select only service categories that accurately describe the work. LinkedIn's available labels must be checked in the account; this draft does not assume exact category names.
- Set remote availability and the actual location.
- Choose “Contact for pricing” until a specific scope is known. Existing package prices remain on the website.
- Allow messages from outside the connection network if receiving project requests is desired.
- Put the three existing case studies in the personal profile's Featured section where the account permits links. LinkedIn currently reserves media within the Service Page for paid tiers.
