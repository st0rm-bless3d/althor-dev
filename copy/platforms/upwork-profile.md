## Overview

I'm Samuel S, the engineer behind Althor Labs. I build AI applications and workflow software, with a focus on Azure, Entra ID, Microsoft 365, and Power Platform.

My work includes a document extraction pipeline that compares field values from multiple models, applies validators, and keeps original outputs alongside reviewed records. It uses TypeScript, Azure Functions, and Durable orchestration.

I also built an enterprise AI governance application: a use-case registry with Entra ID roles, council review, and Teams and SharePoint integration. The public case study describes the architecture without identifying the client.

Alongside client work, I maintain Spire, an independent project for managing my own infrastructure and developing agent workflows. It has a React/TypeScript interface, a retained Rust backend, and Postgres state.

I can help build an AI application, connect it to Microsoft systems, or investigate a specific integration problem. My languages include TypeScript and Python.

I start by agreeing on what the software needs to do and how we'll check it. Access requirements, failure handling, and deployment ownership are part of that scope. The handoff includes the documentation agreed for the project.
