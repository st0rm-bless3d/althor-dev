# Material sources

`metal030-color.jpg` is the unmodified 1024 × 1024 base-color map from
[Metal 030](https://ambientcg.com/view?id=Metal030), by ambientCG.
Downloaded 2026-09-24 from the official `Metal030_1K-JPG.zip` package.
The source describes this material as procedural, not a photographic scan.

License: [Creative Commons CC0 1.0](https://docs.ambientcg.com/license/).
The site permits commercial use and redistribution of raw asset files.
The original JPEG is 239,830 bytes. It is self-hosted and reused in control
surfaces through CSS, with no runtime requests to the asset provider.

Control sizing follows the 44 CSS pixel enhanced target-size guidance:
https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced

Functional labels follow the icon interpretation findings in:
https://www.nngroup.com/articles/icon-usability/
